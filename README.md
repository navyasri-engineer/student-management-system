# Student Management System

A Python-based application to manage student records using SQLite database.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student

## Tech Stack
- Python
- SQLite

## Description
This project implements CRUD operations (Create, Read, Update, Delete) to efficiently manage student data. It demonstrates database integration and backend logic using Python.

## Project Highlights
- Implemented CRUD operations for efficient data management
- Used SQLite for lightweight database integration
- Designed modular functions for clean code structure

## How to Run
1. Install Python
2. Run the file:
   python student_system.py
